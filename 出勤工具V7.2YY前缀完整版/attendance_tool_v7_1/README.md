# V7.2 YY 前缀忽略版

V7.2 YY 前缀忽略更新

使用方法：
1. 如果 YY 与游戏姓名只差一个前缀，勾选“YY 去掉前缀后与游戏 ID 相同：只上传游戏名单”。
2. 上传没有前缀的游戏名单，不用再上传 YY 名单。
3. 在“YY 匹配时忽略的前缀”填写实际前缀，例如：业火圣歌。多个前缀每行一个，留空则关闭前缀忽略。
4. 分别上传游戏、YY 截图并开始识别。YY 识别到“业火圣歌小婵”会匹配名单的“小婵”。
5. 若两边名字还有其他差异，不勾选单名单选项，继续上传双名单；前缀忽略依然可以使用。

规则：
只在 YY 姓名匹配时忽略开头的指定前缀；不改变游戏识别规则，也不把出现在姓名中间或末尾的词删除。
沿用繁简、装饰符号归一化。名单和 OCR 原始文字保留，人工核对可见原始 OCR。
去掉前缀后出现同名或 OCR 低置信度时，仍需人工确认。
修改前缀或切换名单模式后，旧结果会清除，需要重新识别。
单名单模式下导出 YY ID 栏使用名单里的基础姓名；实际带前缀的原始文字保留在 OCR 核对区。

更新 GitHub：
解压更新包，将 attendance_tool_v7_1 文件夹中的四个程序文件及 README 上传到原来同名目录。
四个程序文件是 app.py、core/pipeline.py、core/batch.py、core/ocr_engine.py，必须一起更新并保留子目录。
你的入口若为 出勤工具V7.2双名单完整版/attendance_tool_v7_1/app.py，则在 GitHub 的 出勤工具V7.2双名单完整版 目录上传本包的 attendance_tool_v7_1 文件夹。
应用入口不变；旧工具保持原样。本次未上传 GitHub 或部署线上。

内存与验证：
前缀忽略为字符串匹配，不新增模型，也不加载另一套 OCR；额外内存很小，不能保证云平台永不超限。
64 项本地测试通过，包含单名单界面识别、前缀变更清缓存、同名防误配、原始文字保留、低置信度保护、YY 姓名直接识别避免重复 OCR，以及原有回归。
新功能使用模拟 OCR 输出验证匹配，不代表真实截图的文字识别准确率评测。
免费云部署仍选 Python 3.12，并将 packages.txt 放在仓库最外层。
